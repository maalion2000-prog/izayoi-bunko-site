# 十六夜文庫 台本案B ── 『走れメロス』回（シンの「一目置いた」を結末の主役にする構成）

作成日: 2026-10-31
元にした案: `ep01-hashire-merosu.md`（案A。マモルの「寝返り」が結末の主役）
想定尺: 約11分

## 案Aからの変更点

| 項目 | 案A | 案B（本書） |
|---|---|---|
| 結末の主役 | マモルの寝返り（無責任派→英雄派） | シンがユメに一目置く |
| 最終集計 | 3対1 | 2対2のまま「持ち越し」 |
| 結末の型 | 寝返り＋一目置いた | 持ち越し＋一目置いた |
| 視聴者への投げかけ | 「あなたが5人目なら？」 | 同じ文言だが、**5人目の一票で本当に決まる**構図になる |
| シンの変化 | 札は変えず、ユメに一言認める | 札は変えないが、自分の読み方の穴を自分の言葉で認める |
| マモル | 根拠が出て寝返る | 立場を変えない。王の「遅れて来い」を根拠として提示する役 |
| コールドオープン | シン×リク | シン×ユメ（結末の伏線） |
| 看板コンビ（シン×ユメ）の縦軸 | 弱い | 第1話として成立する |

シンの変化は三段階で積む。**第一ラウンドでは感情の読み方を相手にしない → 第二ラウンドで一度だけ黙る → 王の「遅れて来い」をめぐってユメに自分の言葉（責任・構造）で返され、認める。** 札は最後まで変えない。INTJの盲点「人の感情を軽視」は消さず、自覚するところまでで止める。

## 1. タイトル・サムネ

**タイトル**

```
『走れメロス』メロスは英雄か、ただの無責任男か？｜2対2で決着つかず、5人目はあなた（INTJ×ISTJ×ESTP×INFP）
```

**サムネ文字**
- 大: 「英雄？ 無責任？」
- 小: 「2対2 ─ 決めるのは、あなた」
- 左に無責任派（シン・マモル）、右に英雄派（リク・ユメ）。シンとユメだけ視線を合わせる構図にして、二人の回であることを匂わせる。

**問い**
> メロスは「信実」の英雄か、それとも友を人質にした無責任な男か。

## 2. 出演と配置

案Aと同じ。司会テル（ENFJ）、左にシン（INTJ）とマモル（ISTJ）、右にリク（ESTP）とユメ（INFP）。背景色・話者テロップ・声の三軸の基準値も案Aの表のまま。

**案Bだけの追加指定**
- シンの「間」は基準0.8秒だが、山場（6:30台）の一か所だけ**1.5秒**まで伸ばす。番組を通してシンが最も長く黙る瞬間にする。
- 一目置いたのSEは、案Aでは軽く鳴らしたが、案Bではここが結末なので**SEのあとに1秒の無音**を入れる。
- 立ち絵の移動はしない（寝返りが起きないため）。代わりに「一目置いた」の瞬間、シンの立ち絵だけ一度ユメの方を向く差分があれば使う。なければ視線のテロップで代用。

### 1:30 第一ラウンド ── それぞれの読み方（各40秒）

**シン**: 構造の話をする。［間0.8］メロスは王を除くと決めて城に入った。武器は短剣一本、計画はない。捕まる。ここまでは本人のリスクだ。問題はそのあと。自分の都合で三日欲しいと言い、担保に友を差し出した。［間0.8］失敗したときに死ぬのはセリヌンティウスだ。リスクを他人に移した時点で、英雄の構造じゃない。

**テル**: 冒頭にこうありますね。

［引用：「メロスには政治がわからぬ。メロスは、村の牧人である。笛を吹き、羊と遊んで暮して来た。けれども邪悪に対しては、人一倍に敏感であった。」］

**シン**: そう。作者自身が「わからぬ」と書いている。賢さの話じゃない。無計画の宣言だ。

**テル**: リク、英雄派。

**リク**: 計画があったら、あいつは城に行ってない。［間0.2］王がひどい、許せない、行く。それで行けるやつが何人いる？ 俺たちは普通、行かない。行かない理由を十個考える。メロスは行った。それだけで俺は英雄だと思う。［間0.2］あと、戻ってきた。川が氾濫して、山賊が出て、倒れて、それでも戻った。結果を出したやつを無責任とは呼ばない。

**テル**: マモル、無責任派。

**マモル**: 根拠を順に。［間0.6］一、結婚式を終えたあと、メロスは祝宴で飲んで眠っている。目が覚めたのは翌日の薄明。本文に「寝過したか」とある。二、道中で一度、諦めかけている。

［引用：「ああ、もういっそ、悪徳者として生き伸びてやろうか。」］

**マモル**: 三、戻れたのは、川を泳ぎ切れ、山賊に勝て、湧き水があったからだ。どれか一つ欠ければ友は死んでいる。戻ったのは事実だが、前例として推奨できる行動ではない。

**テル**: ユメ、英雄派。

**ユメ**: ［間1.0］私は、諦めかけたところが、いちばん好き。［間1.0］最初から最後まで強い人の話だったら、たぶん読み返してない。倒れて、もういいやって思って、水の音で立ち上がる。［間0.8］あの場面で、メロスは英雄じゃなくなって、それからもう一回、人になって走る。英雄かどうかって聞かれたら、私は「人として戻ってきた」から英雄だと思う。

**シン**: ［間0.8］感動の構造としては分かる。だが問いは「英雄か無責任か」だ。本人の内面がどう揺れようと、セリヌンティウスの側からは同じことだ。

［T:シン、ユメの読み方を「感動の構造」と呼ぶ ─ 一段階目］

### 4:00 第二ラウンド ── ぶつかる（2分20秒）

**テル**: では、ぶつけます。メロスは「なぜ」走ったのか。本文にはっきり書いてあります。

［引用：「私は、信じられているから走るのだ。間に合う、間に合わぬは問題でないのだ。人の命も問題でないのだ。私は、なんだか、もっと恐ろしく大きいものの為に走っているのだ。」］

**テル**: 「人の命も問題でない」。シン、これは。

**シン**: 自分のためだ。「信じられている自分」を裏切れないから走っている。友の命のためではない。［間0.8］本人がそう言っている。

**リク**: 俺はそこ、逆に読んでる。「間に合うかどうかじゃない」って、計算をやめた瞬間だろ。計算してるうちは走れない。

**シン**: 計算をやめた男を英雄と呼ぶなら、それは無責任と同じ意味だ。

**リク**: 違えよ。計算をやめても走るやつと、計算をやめて止まるやつがいる。

**マモル**: 走った結果が良かったから、そう言える。

**リク**: セリヌンティウスの側の話をするなら、あいつ、自分で言ってるぞ。

［引用：「セリヌンティウス、私を殴れ。ちから一ぱいに頬を殴れ。私は、途中で一度、悪い夢を見た。」］

**リク**: 隠してない。戻って、最初に謝ってる。無責任なやつは、ここを黙る。

**マモル**: 正直であることと、責任を果たしたことは別だ。

**ユメ**: ［間1.0］でも、それって……誰でもそうじゃない？［間0.8］何かを約束して、守れた人は、全員どこかで運に助けられてる。運に助けられなかった人が無責任なんじゃなくて。

**シン**: ［間1.0］……［間0.5］続けてくれ。

［T:シン、初めて黙る ─ 二段階目］

**ユメ**: ［間0.8］ううん。今のは、まだ言葉になってない。あとで言う。

**テル**: では、その「あとで」のために、もう一つ場面を出します。

### 6:20 王の誘い ── 結末の山場（2分）

**テル**: マモル。メロスが村へ帰る前、王が言ったことを。

**マモル**: ［間0.6］記録にある。

［引用：「三日目には日没までに帰って来い。おくれたら、その身代りを、きっと殺すぞ。ちょっとおくれて来るがいい。おまえの罪は、永遠にゆるしてやろうぞ。」］

**マモル**: 王は、遅れることを勧めている。遅れればセリヌンティウスが死に、メロスは許される。

**テル**: シン。構造で読むと、これは何ですか。

**シン**: 裏切るインセンティブの設計だ。［間0.8］遅れれば友は死ぬが、自分は生きて許される。しかも誰もメロスを責めない。王が「遅れて来い」と言ったのだから。合理的な人間は、遅れる。

**ユメ**: ［間1.0］でも、遅れなかった。

**シン**: だから無計画だと言っている。

**ユメ**: ［間1.5］……さっき、言葉になってなかったこと、今言える。［間1.0］シンは、メロスは自分のために走ったって言った。私も、そう思う。［間0.8］でもそれ、無責任の反対じゃない？［間1.0］責任って、誰にも責められない逃げ道があるときに、それでも守ることでしょう。王様は、誰も責めない道を用意した。メロスは、それを断った。［間0.8］合理的じゃない。でも、それを「無計画」って呼ぶのは、たぶん、違う。

［シンの間：1.5秒。この番組でシンが最も長く黙る］

**シン**: ［間1.5］……インセンティブに従わない行動を、私は「説明できない」と言わずに、「無計画」と呼んでいた。［間0.8］それは、私の読み方の穴だ。

［SE:一目置いた。T:一目置いた ─ シン→ユメ。SEのあと1秒無音］

**シン**: 札は変えない。［間0.8］メロスは友の命を賭けた。それは今も無責任だと思う。［間0.8］だが、ユメの読み方には、私の読み方では届かない場所がある。それは認める。

**ユメ**: ［間1.0］ありがとう。［間0.8］私も、シンが最初に言った「セリヌンティウスの側」は、ずっと引っかかってる。たぶん、次の本でも引っかかってる。

**テル**: 平行線のまま、お互いに一目置いた。［間0.4］これが今日の形ですね。マモル、リクは。

**マモル**: 記録しておく。メロスが王の誘いを断った事実は、根拠として追加する。［間0.6］ただし結論は変えない。推奨できる前例ではない。

**リク**: 俺は最初から変える気ねえよ。［間0.2］でもユメ、今の言い方、俺より上手かった。俺が三回言って届かなかったのを、一回で届けた。

### 8:20 最終弁論（各30秒・ショート素材）

［T:最終弁論 ─ 一人30秒。立ち絵は中央1人ずつ。背景はそのキャラの分類色］

**テル**: 最終弁論。一人30秒。シンから。

**シン**: メロスは、友の命を担保に置いて、計画なしで走った男だ。私はそれを今も無責任だと思う。［間0.8］だが今日、一つ分かった。私は構造で説明できないものを、無計画と呼んできた。［間0.8］メロスは、王が用意した逃げ道を断った。構造はそれを説明できない。［間0.8］だから私の答えは、「英雄ではない。だが、私の読み方では測れない男だ」。

**マモル**: 根拠は四つになった。寝た、諦めかけた、運に助けられた。そして、王の誘いを断った。［間0.6］最後の一つは、メロスの側に立つ根拠だ。だが三対一で、前例としては推奨しない。［間0.6］メロスは無責任だった。ただし、無責任な男が王を変えたという事実は、記録に残す。［間0.6］真似をするなら、前の晩に寝ないこと。

**リク**: 考える前に動いた。倒れて、立った。着いた。謝った。［間0.2］全部やってる。英雄ってのは失敗しないやつのことじゃない、最後まで降りなかったやつのことだ。［間0.2］王が「降りていいぞ」って言ったのに、降りなかった。だから英雄。以上。

**ユメ**: ［間1.0］この話の最後の一文は、「勇者は、ひどく赤面した」です。［間1.0］英雄って呼ばれて、赤くなる人。［間0.8］自分を英雄だと思ってない人が、誰も責めない逃げ道を断って、走った。［間1.0］だから私は、英雄だと思う。［間0.8］赤面するところまで含めて。

## 6. 次回への引き継ぎ（縦軸の種）

- 次回冒頭で「5人目の集計」を読む。テルが「先週は○対○で、英雄派が勝ちました」と宣言し、シンまたはユメに一言だけ反応させる。
