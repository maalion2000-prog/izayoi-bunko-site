## 1. タイトル・サムネ

**タイトル**

```
『羅生門』生きるためなら、奪っていいのか？｜「いい」と答えた2人のうち1人が寝返った（INTJ×INFP×ISFJ×ENTP）
```

**サムネ文字**
- 大: 「奪って、いい？」
- 小: 「羅生門 ─ 1人が寝返った」
- 左に「いい」派（ハヤテ・ナギ）、右に「だめ」派（シン・ユメ）。ナギだけ少し中央寄りに置き、揺れる人だと分かる構図。

**問い**
> 生きるためなら、奪っていいのか。

### 1:45 第一ラウンド ── それぞれの読み方（各40秒）

**ハヤテ**: どうも、ハヤテ。逆張り担当。［間0.2］で、今日は逆張りじゃなくて本気で「いい」。老婆の理屈を聞いてくれ。

**ナギ**: ［間1.0］あの……はい。［間0.8］私、理屈は分からないんです。でも、今日食べるものがない人の前に立って、「奪っちゃだめ」って言える人を、私は知らなくて。［間1.0］老婆も、下人も、たぶん死んだ女の人も、お腹が空いてた。［間0.8］その人たちに「だめ」って言うのは、お腹がいっぱいの人だと思うんです。だから、「いい」。……言いたくないけど、「いい」です。

**ユメ**: ［間1.0］「だめ」です。［間1.0］でも、先に白状しておきます。［間0.8］下人が老婆の着物を剥いで、走って行くところ。私、ちょっとだけ、「よかった」って思いました。［間1.0］門の下でずっと動けなかった人が、やっと動いた。その「やっと」に、私は弱いです。［間0.8］だから今日は、自分の「よかった」と戦いながら、「だめ」って言います。

**ハヤテ**: 使わないかもよ？
